MyMental 💭

MyMental é uma plataforma web voltada para saúde mental e produtividade pessoal.
Permite gerenciar metas, registrar emoções, manter um diário pessoal, interagir em chat e fórum, e visualizar profissionais cadastrados.

Funcionalidades Principais

✅ Registro e Login de usuários com senha criptografada.

✅ Gestão de Metas: criar, visualizar e excluir metas pessoais.

✅ Diário Pessoal & Emoções: registrar, visualizar e excluir entradas.

✅ Chat Global & Fórum: postar mensagens e interagir com outros usuários.

✅ Profissionais: cadastro e listagem de perfis com fotos.

✅ Configurações: atualizar dados pessoais e senha.

Tecnologias

Backend: Node.js, Express

Banco de dados: MySQL

Frontend: HTML, CSS, JavaScript (Vanilla)

Autenticação: Express-session, Bcrypt

Uploads de arquivos: Multer

*  Rodando o Projeto  *

Clone o repositório:

git clone https://github.com/seu-usuario/mymental.git


*Instale as dependências:

cd mymental
npm install


*Configure o banco de dados MySQL:

Crie o banco mymental

Crie as tabelas (users, metas_pessoais, diario_pessoal, registro_emocoes, forum_posts, chat_global, profissionais)

* Execute o servidor:

node server.js

* Acesse:

http://localhost:3000


*   Observações  *

Datas devem ser enviadas no formato YYYY-MM-DD HH:MM:SS.

Usuários devem estar logados para acessar recursos protegidos.

Uploads de imagens são salvos em /uploads.
